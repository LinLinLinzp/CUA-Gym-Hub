## P1 — Seed workflows

- [x] **Find a title and open its detail.** Search by case-insensitive title substring or exact catalog ID. Enter submits to results with `q` in the URL. Show artwork, name, year, and type for each result, with a useful no-match state. On detail show available metadata, synopsis, the aggregate IMDb score and the personal score separately, plus labeled Watchlist, Rate, and Add to list controls. Reuse these actions from cards or rows where applicable. Search and viewing write no state.
- [x] **Watchlist · add, remove, and re-add.** Toggle membership from a title detail or title card. Show a selected state and update the watchlist count immediately. The Watchlist supports an explicit Remove action on each row. Add inserts a `watchlist` record with `id`, `userId`, `titleId`, `position`, and `createdAt`. Remove deletes that record and compacts remaining positions. Re-add appends a new membership record. Each action adds a `stateEvents` record with the affected membership ID and linked title ID. Ratings and custom lists are independent of Watchlist membership.
- [x] **Watchlist · browse, prioritize, and set privacy.** Display custom order by default. Provide title search within the Watchlist, type and genre filters, and sorting by date added, title, release year, and IMDb score. Provide an edit view with the full custom-order sequence and a numeric Move to position control with Save. Commit affected `watchlist[].position` values and append a `watchlist.reorder` event. A labeled Public/Private control writes `user.watchlistVisibility` and a `watchlist.visibility` event. Browse controls are transient.
- [x] **Ratings · submit, change, and remove.** From detail or a rating row, open the same dialog with an accessible 1–10 integer choice, Save rating, and Cancel. Preselect the current value on edit and offer Remove rating for existing entries. Save inserts or updates exactly one `ratings` row per `(userId, titleId)` with numeric `value`. Edits retain `id` and `createdAt` and change `value` and `updatedAt`. Remove deletes the row. Append `rating.set` or `rating.remove` with the rating ID, title ID, and before/after values. Refresh the score immediately across views and leave the catalog aggregate fixed.
- [x] **Ratings · browse and set privacy.** Show personal score, aggregate score when available, and rating date. Default to most recently changed rating first and support title, personal score, and year sorts plus title/type/genre filters. Report an empty collection separately from no filter matches. A labeled Public/Private control writes `user.ratingsVisibility` and a `ratings.visibility` event. Browse controls are transient.
- [x] **Lists · create, find, and open.** On Your Lists, show name, visibility, count, updated date, and locally derived cover artwork. Search by list name, sort by updated date or name, and open detail from the name. Create list accepts a trimmed required name up to 255 characters, optional description up to 10,000 characters, and Public/Private with Private preselected. Save inserts a `lists` record and appends `list.create`, then opens its detail. Cancel or validation failure writes nothing.
- [x] **Lists · edit details and delete.** On list detail and in the list index row menu, expose Edit details and Delete list. Save edits to name, description, or visibility in `lists`, updates that row’s `updatedAt`, and appends `list.edit`. Delete uses a named confirmation, removes the `lists` row and its `listItems` in one commit, and appends `list.delete` carrying the removed list ID and member IDs. Return to Your Lists on success and leave the catalog, Watchlist, ratings, and other lists intact.
- [x] **Lists · add, remove, and reorder titles.** Add titles on list detail through a local picker that searches the catalog by name or ID. On title detail, Add to list opens a picker for existing lists, with a path to create a list when there are none. Existing memberships are visibly marked and do not duplicate. Add appends a `listItems` row with `id`, `listId`, `titleId`, `position`, `createdAt`, and `userId`. Remove deletes that membership and compacts the list’s positions. Edit order offers a numeric Move to position control and Save for the full custom order. All three actions update the parent list’s `updatedAt` and append the corresponding `list.item.add`, `list.item.remove`, or `list.reorder` event. Show result counts and allow filtering by title/type/genre and sorting by custom order, date added, or title. View sorting writes nothing.
