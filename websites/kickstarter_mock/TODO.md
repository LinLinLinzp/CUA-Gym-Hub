This is the pre-signed-in creator workspace. Authentication, identity checks, payments, public pledging, fulfillment logistics and external notifications sit outside its workflows. Use original local campaign artwork, synthetic records and the Kickstarter name as text. Start a persistent server with `Start-Process -WindowStyle Hidden` and an absolute Vite entry point. Put scratch files in a gitignored directory or remove them after testing. All functional tests use localhost.
