## P1 — Primary workflows

Every create appends a record with an ID, `createdById`, ISO `createdAt`, `updatedById` and ISO `updatedAt`. Updates stamp `updatedById` and `updatedAt` using the current actor and `new Date().toISOString()`. Use project membership for people pickers. List the fields below in the verifier table, including the shared metadata.

### To-dos

- [x] **Create and manage lists.** The To-dos tool lists active project lists with title, optional description, progress and a contextual **Add a to-do** link. **New list** opens a form with name and description; a name containing only spaces gets an inline error. The list title links to detail. The detail menu provides Edit and Put in the trash, with confirmation for trash. **Writes** create `todoLists[]` with `projectId, name, description, position, status: 'active'`; edit `name, description`; trash sets `status: 'trashed'`. Child records retain their own status and become visible again when the list is restored. Progress is derived from active children.
- [x] **Add, edit and assign a to-do.** Open an inline form inside the list with title, multi-select **Assigned to** and **When done, notify**, an optional due date or date range, and Notes. Show chosen people as removable name chips. Require a title and reject ranges ending before their start. Render metadata next to the checkbox and link the title to detail, which includes an Edit action. **Writes** create `todos[]` with `projectId, listId, title, notes, assigneeIds, completionNotifyIds, startsOn, dueOn, position, completed: false, completedById: null, completedAt: null, status: 'active'`. Editing updates `title, notes, assigneeIds, completionNotifyIds, startsOn, dueOn` and preserves completion.
- [x] **Complete, reopen, move and trash a to-do.** An accessible checkbox works from list and detail. Show completed items separately and refresh counts immediately. Provide **Move** in the item menu to choose another active list in the same project, and allow reordering open to-dos by drag or menu. Provide confirmed **Put in the trash**. **Writes** update `todos[].completed, completedById, completedAt` (reopen resets actor and time to null); move changes `listId, position` and stamps affected rows whose position changes; reorder changes `position` on affected rows; trash sets `status: 'trashed'`. A dated moved item appears once in the same project Schedule.
- [x] **Find and discuss tasks.** Filter lists and to-dos by text and tasks by assignee, due state and open/completed state. On to-do detail, show oldest-first comments with author, time and an **Add a comment** editor. **Writes** add `comments[]` with `projectId, parentType: 'todo', parentId, bodyHtml, status: 'active'`. Filters and expansion are transient.
