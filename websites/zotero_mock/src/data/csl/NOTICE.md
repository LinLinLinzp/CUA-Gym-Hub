# Citation Style Language resources

These unmodified local style and locale definitions are from the Citation Style Language project's [styles](https://github.com/citation-style-language/styles) and [locales](https://github.com/citation-style-language/locales) repositories. Each file identifies its contributors and carries the [Creative Commons Attribution-ShareAlike 3.0 license](https://creativecommons.org/licenses/by-sa/3.0/). The styles are APA 7th edition, MLA 9th edition in-text, and Chicago 18th edition author-date. The fixed locale is English (United States).
