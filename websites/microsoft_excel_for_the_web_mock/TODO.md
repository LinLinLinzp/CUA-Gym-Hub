## P1 — Required interactive workflows

### Workbooks

- [x] **W01 — Home, discovery and opening:** use the 68px left rail, local template cards and 52px file rows; Recent/Favorites/Shared tabs, name/owner search, name/last-opened sort, owner/avatar/location metadata, row ellipsis actions and useful no-results states. Search/sort/tab changes are local view state. Clicking a workbook opens its editor and records one explicit open: `workbooks[].lastOpenedAt`, `operations[]` type `workbook.open`. Mounting or reloading an editor does not update timestamps. Favorite star updates `workbooks[].favoriteUserIds` and adds `workbook.favorite`.
- [x] **W02 — Create and rename:** Blank workbook creates an owned `Book N` with one visible `Sheet1`, then opens it; Budget and Sales templates create independent copies of local template content. Rename from filename dropdown or home ellipsis; trim surrounding whitespace, disallow empty names and OneDrive filename characters `" * : < > ? / \\ |`, show inline validation, and preserve `.xlsx` as display extension. Cancel/invalid names write nothing. Writes: new `workbooks[]`, `sheets[]`, optional template `cells[]/tables[]`; rename updates `workbooks[].name/updatedAt/updatedBy`; `operations[]` types `workbook.create/rename` with template/source IDs where applicable.
- [x] **W03 — Save a Copy:** File menu opens a name/location dialog defaulting to `<name> - Copy`; create new workbook/sheet/cell/table/filter/sort/chart/comment IDs and remap internal references and formula dependency sheet IDs. Do not copy shares, sharing links or original operations. Set current user as owner, `sourceWorkbookId`, and selected sheet to its copied equivalent. Writes: copied records, new `workbooks[].sourceWorkbookId`, `operations[]` type `workbook.copy` with source/target IDs. Original records stay unchanged.
- [x] **W04 — Delete/restore:** home ellipsis Delete uses a confirmation naming the workbook; mark `workbooks[].status='deleted'`, `deletedAt/deletedBy`, hide it from normal lists and show a recycle-bin view within My Content. Restore sets `status='active'`, clears deletion fields. Retain child records, shares and links for restoration but treat them as unavailable while the workbook is deleted. Writes: workbook lifecycle fields and `operations[]` type `workbook.delete/restore`.

### Sheets

- [x] **S01 — Add, switch and rename:** bottom + adds next unused `SheetN`, All Sheets lists visible sheets, tab click switches, double-click/context Rename opens inline editing. Sheet names are case-insensitively unique per workbook, 1–31 characters, forbid `/ \\ ? * : [ ]`, leading/trailing apostrophe and reserved `History`; errors remain inline. Rename must tokenize/rewrite same-workbook cross-sheet references without changing quoted string literals, retain stable sheet IDs and recalculate affected cells. Writes: `sheets[]` identity/name/position/timestamps; `workbooks[].activeSheetId`; affected `cells[].formula/input/dependencies/value/error`; `operations[]` type `sheet.add/select/rename`.
- [x] **S02 — Duplicate, reorder, tab color:** tab context Duplicate copies cells, tables, criteria and optional comments/charts with new IDs, a unique valid name and inserted position after source; explicit self-sheet references target the duplicate and other-sheet references retain targets. Reorder by drag and an accessible Reorder dialog; normalize positions to contiguous zero-based indices. Tab Color palette supports No Color. Writes: new linked records and `sheets[].sourceSheetId`, all affected `sheets[].position`, `sheets[].tabColor`, workbook metadata, `operations[]` type `sheet.duplicate/reorder/color`.
- [x] **S03 — Hide, unhide and delete:** context menu Hide chooses another visible tab, Unhide dialog lists hidden sheets; reject hiding/deleting the last visible active sheet. Delete confirms the sheet name, soft-deletes it and marks child objects effectively unavailable; references to deleted sheet cells evaluate to `#REF!`. In a zero-sheet injected workbook, + creates the first valid sheet without requiring seed data. Writes: `sheets[].visibility/status/deletedAt/deletedBy`, workbook active sheet/metadata, affected formula cells, `operations[]` type `sheet.hide/unhide/delete`.

### Cell editing and formulas

- [x] **E01 — Edit cells and formula bar:** click selects; typing replaces; double-click/F2 edits existing input; formula bar edits selected cell, with Cancel/Enter buttons; Enter commits and moves down, Tab commits and moves right, Escape cancels, Delete clears selected contents while keeping formatting. Name box navigates to valid A1/range; arrow/Shift+arrow expand selections; status bar Count/Sum/Average derives from selected numeric cells. Inputs remain draft-local until commit. Writes: sparse `cells[]` upserts with input/value/type/formula/error/dependencies/editor/timestamps, dependent recalculation and `operations[]` type `cell.edit/clear` including affected IDs and address range. Blank unformatted cleared cells may be removed with a structured clear operation.
- [x] **E02 — Paste, fill and undo/redo:** paste TSV rectangles through an internal clipboard with browser clipboard enhancement/fallback; Copy/Cut/Paste context and ribbon commands, fill handle drag or Fill Down. Preserve text/number distinction and adjust relative A1 references on copy/fill while `$` anchors stay fixed; cut moves references appropriately. Undo/redo last 20 cell/content/format transactions during the active session using in-memory inverse patches, one transaction per rectangle. Do not promise persistent undo history or undo sharing/deletion. Writes: `cells[]`, formula dependents, workbook metadata, `operations[]` type `range.paste/cut/fill` or `edit.undo/redo`, referencing original operation IDs. Clipboard permission failure leaves a usable manual paste input.
- [x] **F01 — Formula evaluation:** support case-insensitive `SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, ROUND`, arithmetic `+ - * / ^`, parentheses, comparisons and A1 ranges, absolute/mixed references, boolean/string literals and same-workbook quoted sheet references. Formula text includes `=` and remains visible in the formula bar; grid shows evaluated value. Use a bundled evaluator/parser, never `eval`/`Function`; do not hard-code seeded addresses. On user commit recalculate dependency chains synchronously with cycle detection; persist `cells[].formula`, `input`, `value`, `valueType`, `error`, `dependencies`. Unsupported names → `#NAME?`, divide by zero → `#DIV/0!`, deleted/bad reference → `#REF!`, incompatible type → `#VALUE!`, cycle → `#CIRC!` (documented sandbox convention). Errors have `value=null`, not NaN/Infinity. Reads may derive calculations for injected missing caches but must not post to repair them.
- [x] **F02 — AutoSum and insert function:** Home/Formulas AutoSum proposes a contiguous numeric range above, otherwise left; show editable `=SUM(...)` draft and range outline, Enter commits, Escape cancels. Function dropdown offers Sum/Average/Count Numbers/Max/Min; fx dialog searches supported functions, shows signature and inserts a draft. Writes only on commit: formula `cells[]` and recalculated dependents, `operations[]` type `formula.set` with formula/address/dependency IDs. Existing formulas must be editable after reload.
- [x] **F03 — Dependency correctness:** support editing a precedent on another sheet, formula overwrite/clear, range paste and sheet rename/delete/duplicate through the same transaction engine. Example: `Sales!G2 = E2*F2`, `Summary!B2 = SUM(Sales!G2:G121)`; changing Sales E2 from 10 to 12 with F2=25 yields G2=300 and Summary +50. Filtering must not change ordinary SUM totals. Writes: changed and dependent `cells[]` with coherent caches/dependencies; operation lists recalculated cell IDs. Acceptance includes a two-level dependency chain, `$F$2` fill, unknown function, division by zero and a cycle.
- [x] **E03 — Formatting:** Home font family/size, bold/italic/underline, fill/text palette, alignment, wrap and General/Number/Currency/Percentage/Date formats act on the selected range; numeric values remain numeric. Merge & Center rejects conflicting nonempty cells with a warning/confirmation and records the retained top-left content; Unmerge restores independent coordinates without inventing discarded values. Writes: `cells[].format`, optional `sheets[].mergedRanges`, cell content if confirmed merge discards data, workbook metadata and `operations[]` type `range.format/merge/unmerge`. Current selection formatting drives ribbon toggles.

### Tables, filters and sorting

- [x] **D01 — Table and range filter setup:** Data > Filter enables/removes arrows on the selected rectangular header range; blank selection inside data expands to its contiguous used range. Table headers get filter arrows; table name is unique per workbook. Writes: `sheets[].autoFilterRange`, `tables[]` name/range/column definitions/style/filterEnabled; inserted/moved `cells[]` when generating headers; `operations[]` type `filter.enable/disable/table.create`. Filter disable clears that range's criteria.
- [x] **D02 — Value filters:** header dropdown contains sort commands, Clear Filter from column, Search, Select All, distinct values and `(Blanks)` when present, scrollable checklist, OK and Cancel. Same-column values use OR, columns combine with AND; show funnel icon, retained source row numbers, and visible row count. Select All clears that column's predicate; selecting none disables OK until a value is chosen. Writes: upsert `filters[]` with workbook/sheet/table-or-range/column, `kind='values'`, `values`, `status='active'`, actor/timestamps; Clear sets status `cleared`; `operations[]` type `filter.apply/clear`. Data is hidden by derivation; no cell deletion or content reorder.
- [x] **D03 — Custom filters, clear and reapply:** Text Filters Equals/Contains/Begins With; Number Filters Equals/Greater Than/Less Than/Between; Date Filters Before/After/Between with valid date input. Reapply evaluates stored predicates against current values; Data > Clear clears all criteria but retains filter arrows; Data > Filter removes arrows for plain ranges (table dropdown remains with table filter setting). Writes: `filters[].kind/predicates/join/status/updatedAt/updatedBy`, filter configuration where changed, workbook metadata, `operations[]` type `filter.apply/clear/reapply/disable`. Reapply explicitly records the action even if the matching row set is unchanged. Test filtered empty results and editing visible cells.
- [x] **D04 — Sort complete records:** dropdown A–Z/Z–A or Smallest/Largest and Data sort dialog choose one or more columns, direction and header flag. Warn/offer Expand selection for partial data-column selections. Stable typed sort, blanks last, preserve header and move whole cell rows with formatting together; never detach amounts from their orders. Track coordinate permutation, relocate cell records, adjust moved formulas and recalculate dependencies, then evaluate active filters. Writes: `sorts[]` range/keys/status, supersede earlier config for same range, changed `cells[].row/column/address/input/formula/dependencies/value`, workbook metadata and `operations[]` type `range.sort` with before/after row permutation. No separate hidden copy of table data.
