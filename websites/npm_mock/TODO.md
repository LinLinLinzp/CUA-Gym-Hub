## P1 — Packages

- [x] **P1.1 · Inventory and package detail.** Show a package name, description, current version, scope, visibility, status, weekly downloads, and last publish date per row. The detail view exposes Overview, Versions, and Settings, with a copyable install command and the deprecation message when applicable. These operations write no records.
- [x] **P1.2 · Change package visibility.** In Settings, let owners of scoped packages choose Public or Private and save. Require the existing owner plan to support private packages and show a clear reason when unavailable. Confirm a private-to-public change before saving. Update `packages[].visibility`, `updatedAt`, and `updatedBy`. The row, filters, detail, and organization package list reflect the saved change immediately.
- [x] **P1.3 · Deprecate and restore a package.** In Settings, require an explanatory message and exact package-name confirmation to deprecate an owned package. Keep the package accessible in the account inventory and show the warning in its detail view. Confirmation writes `packages[].status = "deprecated"`, `deprecationMessage`, `deprecatedAt`, `deprecatedBy`, `updatedAt`, and `updatedBy`. Restoring sets `status = "active"`, clears the three deprecation fields, and updates `updatedAt` and `updatedBy`.
