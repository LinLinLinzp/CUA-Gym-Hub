## P1 — Seed workflows

- [x] **Research folders — organize matters.** List active folders with name search, sort, item counts and **New folder**. Folder detail shows breadcrumbs, children, searchable items and folder actions. New accepts an optional parent. Trim names, require a name and reject duplicates among active siblings. Confirm archive and offer restore in **Recycle bin**, checking parent availability and name conflicts. **Writes:** creation appends folders[]; rename changes name; archive and restore change status. Each existing-row change sets updatedAt and updatedBy. Archiving hides descendants through ancestry and preserves their explicit status and item records.
- [x] **Research folders — save and curate material.** Use one destination picker for documents, searches and citations with inline folder creation. Save a document once per active folder. Save a named search with its query and filter snapshot and offer **Run saved search** from that item. Search within a folder by name, citation, query and note. Users can open documents, rename saved searches, add/edit/clear item notes, move or copy eligible items to another active folder, and remove or restore items. Confirm removal and reject duplicate move, copy and restore destinations. **Writes:** save and copy append folderItems[]; move changes folderId; rename changes title; note edits change note; remove and restore change status. Existing-row mutations set updatedAt and updatedBy. Inline folder-and-item creation writes both arrays together.
- [x] **Citations — find and check authority.** Accept a citation or case name. Show case, year, court and citation, with normalized exact reporter citations and aliases before partial matches. Open a Shepard’s report from lookup or document detail and show overall treatment plus citing decisions filterable by treatment and jurisdiction. Provide empty and unavailable report states. **Writes:** explicitly choosing to run or open a supported report adds a citationActions[] record of type checked with documentId, optional query, actor and timestamp. Direct report navigation, filtering and reloads write nothing.
- [x] **Citations — preview, copy and save.** Open **Copy citation** from a document or report, preview the supported formats and offer an optional local link. Support seeded Standard and ALWD case citations and the header citation for other citable records. Copy the previewed plain text and provide selectable text with retry on clipboard failure. **Save citation to folder** uses the same picker as other research items. **Writes:** successful copy appends a citationActions[] record of type copied and updates profile.citationFormat when a supported style was chosen. Save appends a folderItems[] record of kind citation and a citationActions[] record of type saved with folderId and folderItemId in one save. Both log the actual format, includeLink and citationText.
- [x] **Alerts — create and configure monitors.** Offer **New alert** in Alerts and contextual entry points from search results and citation reports. Search alerts store a query, filter snapshot and monitored content types. Shepard’s alerts store a documentId and monitored treatment scope. Both accept a required title, optional description and client, delivery choice, cadence if email delivery is selected, and optional expiration. Existing monitors can edit metadata, monitoring scope and delivery, with the original watched search, its filters or cited authority fixed. **Writes:** create appends alerts[] with status active and variant source, monitor and delivery fields. Edit changes those editable fields and update metadata on the same record. All preferences remain local.
- [x] **Alerts — review results and manage lifecycle.** Search by title or source, filter by type and status, and sort by date, title or frequency. Open an alert for configuration and dated results with links to their documents. Allow explicit mark read/unread, pause/resume, and delete with confirmation. Show an empty results state for new alerts without seeded hits. **Writes:** pause/resume/delete change alerts[].status, updatedAt and updatedBy. Marking results changes alertResults[].status, readAt, updatedAt and updatedBy. Expiration and counts derive on render. Opening an alert or result writes nothing.
