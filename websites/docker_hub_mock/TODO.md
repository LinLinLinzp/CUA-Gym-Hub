## P1 — Repositories

- [x] **Find repositories.** Default to all accessible namespaces and newest updated first. Provide search for short name, qualified name, and description, a namespace selector, Public/Private visibility filter, and Updated/Name/Pulls sorting. Display qualified name, short description, visibility, active tag count, pulls, and last updated. Paginate at 12, reset the page when filters change, and distinguish an empty namespace from a search with no matches. Opening a row shows General with breadcrumbs and tabs. Writes no state.
- [x] **Create a repository.** Open a form with Namespace, Repository name, Short description, and Visibility. Default to the current namespace when selected and Private. Trim input, require 2–255 characters from `a–z`, `0–9`, hyphen or underscore for the repository name, limit description to 100 characters, and prevent a duplicate active name within the namespace. On submit open General for the new repository. Writes a `repositories[]` record and a `repository.created` event in `activity[]`.
- [x] **Update repository information.** On General, edit the short description and plain-text overview with Save and Cancel. Show the qualified image name and a copyable pull reference. The namespace and name remain fixed for the lifetime of the repository. Writes `repositories[].description`, `overview`, `updatedAt`, `updatedBy` and a `repository.updated` event for changed values. Copy writes no state.
- [x] **Change repository visibility.** In Settings, show the current setting and the consequence of switching to Public or Private. Confirm before applying. Writes `repositories[].visibility`, `updatedAt`, `updatedBy` and a `repository.visibility_changed` event.
- [x] **Delete a repository.** In Settings, require the qualified repository name before confirmation. Show the affected tags and team grants as counts. Return to the repository index and make the deleted route resolve to an item-unavailable state. In one save, set the repository and its active tags and grants to `status: 'deleted'` with deletion and update metadata, and append `repository.deleted` with their affected IDs to `activity[]`. Other repositories and teams stay available.

## P1 — Tags

- [x] **Find and inspect image tags.** In a repository's Tags tab, search by tag name, filter by platform, and sort by update time or name. Show tag, digest, platforms, compressed size, and last pushed time. Open tag details from the tag name or digest. Show the full digest, available platform entries, and a copyable, tag-qualified pull reference. Display missing optional metadata with a dash. Search, inspection and copying write no state.
- [x] **Add a tag from an existing image.** Sandbox workflow. On a tag detail page, let the owner select Add tag, then enter a new tag name using `^[A-Za-z0-9_][A-Za-z0-9_.-]{0,127}$`. Reject an existing active name in the same repository. Copy the source tag's image metadata into a new tag with its own ID, the current timestamp, and a source link. Open the new tag detail on success. Writes `tags[]`, the parent repository's update metadata, and a `tag.created` event. This models retagging an existing image locally without running a Docker CLI or contacting a registry.
- [x] **Delete one or more tags.** Enable row selection for active mutable tags and show how many are selected. Confirm by naming the selected tags and keep the selection visible while the dialog is open. Unavailable rows and immutable tags cannot be selected for deletion. Set only the selected `tags[]` records to `status: 'deleted'` with deletion and update metadata. Update the parent repository timestamp and actor, and append one `tag.deleted` event with all affected tag IDs. Other tags sharing the digest remain active.
