- [x] **S1 · Spaces.** Filter by SDK, open a seeded Space and show an original local preview with its status. Create a Space with name, description, SDK, and visibility. - [x] **A1 · Request access and manage gating.** A user without access can read the public card of a gated model or dataset, view current request status, and use a labeled consent form to request file access. Manual gating creates a pending request and automatic gating creates an accepted request. Owners can switch gating between off, auto, and manual on public models and datasets and open a repository-filtered review view from Settings.
