## P1 — Primary workflows

- [x] **Apps.** Show name, status, region, stack, and updated time per row. Provide case-insensitive name search, region and status filters, sorting, clear filters, and distinct empty states for an empty workspace and no matches. Open the app from its row. **Create app** asks for name and United States or Europe; validate unique names within the active workspace, up to 30 lowercase letters, digits, and hyphens, beginning with a letter and ending alphanumerically. Route to Overview on success. Overview shows the active release and counts derived from related records. In Settings, rename with the same validation and delete only after the current name is entered in a confirmation. **Writes:** create an `apps` record and initial active `releases` v1 with a linked `appEvents` record. Rename updates the app name and modification metadata and appends `appEvents` with old and new names. Delete marks the app deleted, marks its active formations and add-ons retired or removed, and appends a deletion event with affected IDs. Exclude deleted resources from normal lists while retaining their records for verification.
- [x] **Dynos.** Resources presents each process type, command when supplied, dyno size, quantity, and operational status. Edit formation in a labeled dialog with size selection, integer quantity, inline limits by size, and a confirmation. Quantity zero stops the process and remains visible so users can scale it back up. Offer **Restart all dynos** with an affected formation summary and disable it when nothing is running. **Writes:** scale/resize updates the related `formations` row and appends a `dynoEvents` record with before/after quantity and size. Restart stamps each running formation and appends one event with affected IDs and total quantity. A restart completes in the same user action with no scheduled writes.
- [x] **Add-ons.** Resources lists provisioned add-ons with service, instance name, plan, status, and monthly cost. **Find add-ons** opens a searchable local catalog. Select a service and plan, review the monthly amount, and confirm provisioning for the current app. From a row, change to another offered plan or confirm removal using the displayed instance name. Filter removed instances out of the active list. **Writes:** provision inserts an `addOns` record, plan change updates `planKey` and `monthlyPrice`, removal sets status and removal time. Each action appends an `addOnEvents` record with the app, instance, and relevant before/after values, and appends an `add_on` release and activates it in the same transaction.
- [x] **Releases.** Show newest version first, active marker, description, actor, status, source revision when available, and date. Open details from a version row. Offer **Deploy revision** for a synthetic revision and optional description, and **Rollback to this release** from an eligible older release with a summary and confirmation. Expired, failed, and already-active releases are ineligible. **Writes:** deployment or rollback appends a `releases` record with the next app-scoped version and updates `apps.activeReleaseId` and modification metadata. Rollback records `rollbackToReleaseId` and uses the target revision if available. Keep historical release rows and current add-on and dyno records intact during rollback.
