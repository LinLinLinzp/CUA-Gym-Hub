## Ground rules (read before coding)
1. **State**: copy `templates/dataManager.js` → `src/utils/dataManager.js` *unchanged*; use `templates/state-api.js` in `vite.config.js`. Seed in `src/data/seed.js` (`createInitialData()`, deterministic, fixed ids & fixed ISO dates). `APP = 'medium'`.
2. **Only user actions write state.** No `setInterval`, no "live" counters, no writes on page load or route mount. In particular: reading history and notification `read` flags are written from **click handlers**, never from `useEffect` on mount. Debounced autosave is fine (it is triggered by typing).
3. Every business action writes a **structured record** (ids, status enums from data_model.md, numbers as numbers, `createdAt/updatedAt = new Date().toISOString()`). Toasts are decoration only.
4. Must render any injected world: empty arrays, 1 record, 500 records, missing optional fields, dangling ids. Guard every `.map/.filter` (`(state.x ?? [])`).
5. Offline: no Google Fonts/CDNs/remote images. `@fontsource/source-serif-4`, `lucide-react`, generated SVG art. Real brand: "Medium" logo & copy; never "Mock"/"Clone".
6. Internal links that leave the router use `withSid()`; React Router navigation must preserve `?sid=` (wrap `Link`/`navigate` in helpers that append the current search's `sid`).
7. Relative dates ("2d ago") are computed from `new Date()` at render time.
8. Add `aria-label`s to every icon-only button (e.g. "clap", "Respond", "Add to list", "More options", "Share", "Notifications", "Close") — agents rely on the accessibility tree.

## Workflow → State map (SEED must-haves; every row is a P0/P1 item below)

| Workflow | User action | Records written (see data_model.md) |
|----------|-------------|-------------------------------------|
| Drafts | Type in new story | `stories[]` + `{id, authorId:'u_maya', status:'draft', title, subtitle:'', body[], wordCount, readingTime, createdAt, updatedAt, publishedAt:null}` |
| Drafts | Keep editing (autosave) | same story: `title`, `body[]` (`text`+`html`), `wordCount`, `readingTime`, `updatedAt` |
| Drafts | Delete draft | story removed from `stories[]`; any `submissions[]` for it set `status:'withdrawn'` |
| Publish | Publish now | story `status:'published'`, `publishedAt`, `updatedAt`, `topicIds[]`, `memberOnly`, `emailSubscribers`, `previewTitle/Subtitle/Image`, `slug`, `publicationId` |
| Publish | Schedule for later | story `status:'scheduled'`, `scheduledFor` (ISO, future) |
| Publish | Edit published → Save and publish | story `title/subtitle/body/updatedAt` |
| Publish | Unlist / relist / allow responses / slug / license | story `visibility`, `allowResponses`, `slug`, `seoTitle`, `seoDescription`, `license`, `updatedAt` |
| Publish | Delete published story | story removed; its list items removed from all `lists[].items` |
| Lists | Save story to list (bookmark picker) | `lists[i].items[]` + `{storyId, note:'', addedAt}`; `lists[i].updatedAt` |
| Lists | Remove from list | item removed; `updatedAt` |
| Lists | Create list | `lists[]` + `{id, ownerId, name, description, visibility, isDefault:false, items:[], createdAt, updatedAt}` (+ first item if created from picker) |
| Lists | Edit list info / privacy | `name`, `description`, `visibility`, `updatedAt` |
| Lists | Add/edit item note | `items[k].note`, `updatedAt` |
| Lists | Delete list | list removed (never the default Reading list) |
| Lists | Save someone's list / unsave | `listSaves[]` add/remove `{id, userId, listId, createdAt}` |
| Responses | Respond to story | `responses[]` + `{id, targetType:'story', targetId, parentResponseId:null, authorId:'u_maya', body, clapCount:0, hidden:false, edited:false, deleted:false, createdAt, updatedAt}` |
| Responses | Reply to response | same with `parentResponseId` |
| Responses | Edit own response | `body`, `edited:true`, `updatedAt` |
| Responses | Delete own response | `deleted:true`, `updatedAt` (or remove if it has no replies) |
| Responses | Hide response on own story / unhide | `hidden`, `hiddenById`, `updatedAt` |
| Responses | Clap a response | `claps[]` upsert `{targetType:'response', targetId, count}` |
| Publications | Create publication | `publications[]` + full record (`ownerId:'u_maya'`, `editorIds:['u_maya']`, `writerIds:[]`, `followerCount:0`, …) |
| Publications | Edit info/homepage/settings | `name`, `tagline`, `description`, `topicIds`, `navItems`, `logoColor`, `submissionPolicy`, `submissionGuidelines`, `featuredStoryIds`, `updatedAt` |
| Publications | Add / remove writer, promote to editor | `writerIds`, `editorIds`, `updatedAt` |
| Publications | Submit draft to publication | `submissions[]` + `{id, storyId, publicationId, submittedById, status:'pending', noteToEditors, createdAt, updatedAt}`; story `publicationId` |
| Publications | Withdraw / resubmit | submission `status:'withdrawn'` (+ story `publicationId:null`) / `status:'pending'` |
| Publications | Editor approve & publish | submission `status:'approved'`, `decidedById`, `decidedAt`; story `status:'published'`, `publishedAt` |
| Publications | Editor request edits / decline | submission `status:'edits_requested'|'declined'`, `editorNote`, `decidedById`, `decidedAt` (decline: story `publicationId:null`) |
| Publications | Publish directly into a pub you edit | story `publicationId`, `status:'published'` (no submission) |
| Publications | Remove story from publication | story `publicationId:null`, `updatedAt` |
| Publications | Follow / unfollow publication | `follows[]` add/remove `{targetType:'publication'}`; publication `followerCount ±1` |
