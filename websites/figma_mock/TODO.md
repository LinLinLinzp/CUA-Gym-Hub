## P1 — Files

- [x] **Browse and find files.** Show card and list views with name, folder or Drafts, last edited time, preview, and an accessible action menu. Files, Drafts, Starred, folders, and Trash have their own scopes. Search matches file and folder names case-insensitively across active files and folders within the current workspace from Files, or within the current scope on the other screens. Offer sort by Last edited and Name, with stable tie-breaking. Highlight the active scope and provide an empty or no-results state with an applicable action. Open an active file into its design route. These controls read `files`, `folders`, and `fileStars`.
- [x] **Create, rename, and organize files.** **New design file** prompts for a nonblank name and creates a design in the current folder or Drafts, then opens the first page. Rename preloads the current name. Move uses a picker of active workspace folders and Drafts. Reject a move to the current destination. Duplicate creates an active **Copy of …** in the same location for an editable file, or in Drafts for a view-only file. Deep-copy document content and remap page, layer, and local component references while preserving external published sources. Copying creates fresh defaults for link access and leaves behind comments, grants, favorites, and publication history. **Writes** — creation and duplication append `files` and `pages`, and duplication also appends copied `layers` and `components`; the copy records `files[].sourceFileId`. Rename updates `files[].name`. Move updates `files[].folderId`. Both stamp `updatedAt` and `updatedById`. Star and unstar upsert `fileStars` for the file and current user with `status` and audit metadata.
- [x] **Trash and restore files.** Prompt for confirmation before moving a named file to Trash. Hide it from active lists and prevent editing from a direct link. Trash shows its original destination and offers Restore. Restore into the original active folder or Drafts if that folder is missing or unavailable. **Writes** — set `files[].status`, `trashedAt`, `trashedById`, and edit metadata on trash; restore sets `status=active`, clears the trash fields, and stamps `restoredAt`, `restoredById`, and edit metadata. Set `folderId=null` if the original folder is unavailable. Related records keep their IDs through trash and restore.

## P1 — Comments

- [x] **Pin and post feedback.** In an open file, choose **Comments**, then **Add comment** or press C outside form fields. Click an empty canvas location or a layer to anchor the composer on the selected page. Validate trimmed nonempty text and cancel with Escape. Submitting shows a numbered pin and a panel entry with page, author, body and time. Clicking a pin or entry opens the thread and its page. **Writes** — append one `commentThreads` record with `fileId`, `pageId`, optional `layerId`, finite normalized `x` and `y`, `body`, creator, timestamps, and `status=open`.
- [x] **Reply, resolve, and reopen.** Open a thread and post a nonblank reply. Show replies in ascending time order. Resolve from the thread and hide it by default from the canvas and panel. **Show resolved** includes resolved pins and entries and gives access to **Reopen**. Allow search across thread and reply text in the current file. **Writes** — append a `commentReplies` record linked by `threadId` and update the parent thread's `updatedAt` and `updatedById` in the same transaction. Resolve sets `commentThreads[].status=resolved`, `resolvedAt`, `resolvedById`, and update metadata. Reopen sets `status=open`, clears the resolve fields, and stamps `reopenedAt`, `reopenedById`, and update metadata.

## P1 — Components

- [x] **Create and name a main component.** Open **Layers** on a seeded page and select an eligible shape, text layer, or frame from the list or canvas. On a blank page, **Add shape** provides a usable starting layer. **Create component** opens a name and optional description form, prefilled from the selected layer. Convert the selected layer to a main component while retaining its geometry and children. Show the main in Layers and under **Local components** in the searchable **Assets** drawer. Provide an edit action for the main component name and description. **Writes** — Add shape appends `layers` and stamps the file's edit metadata. Component creation appends `components`, sets the source layer's `kind=component`, `componentId`, `name` and edit metadata, and stamps the file. Editing updates `components[].name`, `description` and edit metadata, updates the source layer's name and edit metadata if renamed, and stamps the file.
- [x] **Publish and insert reusable instances.** In Assets, list local components and published components from other active, accessible files. **Publish library** in the source file shows eligible components and requires at least one selection. Confirm to make the selected mains available in other files. From another editable file, search Assets, select a component, and **Insert instance** onto the current page. Support inserting local components before publication. Display the new instance on the canvas and in Layers, with a link to the source main alongside its details. **Writes** — publish sets `components[].status=published`, `publishedAt`, `publishedById` and edit metadata for selected mains, and stamps the source file. Insert appends a `layers` record with `kind=instance`, source `componentId`, destination file and page IDs, geometry and audit fields, then stamps the destination file. Keep the link to the shared main when inserting across files.

## P1 — Sharing

- [x] **Invite and manage people.** **Share** opens the same dialog from a file menu or the editor header. List the owner, active direct grants, and pending invites. Accept a synthetic directory match or typed email, choose **Can view** or **Can edit**, and submit with **Invite**. Validate and normalize email, reject the owner and duplicate current grants, show inline errors, and allow re-inviting a removed recipient. Directory users get active grants. An unknown address gets a pending grant. Manage role or confirm removal in the same dialog. **Writes** — append a `fileAccess` record on invite with the file ID, normalized email, optional user ID, role, status and audit fields. - [x] **Configure link access and copy a link.** In Share, set the audience to **Only invited people** or **Anyone with the link**, and choose **Can view** or **Can edit** for the latter. Offer a selectable URL if clipboard access fails. Direct links use the stored synthetic actor and honor effective access. **Writes** — update `files[].linkAccess` with `audience`, `role`, `updatedAt`, and `updatedById` on save. Copying a link only reads this policy and writes to the clipboard.
